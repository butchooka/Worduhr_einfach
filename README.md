# Worduhr_einfach
Meine erste 3D druckbare Version von 2024, jetzt mit ESPHome + Arduino Firmware

Stand 10/2026 DE Version

--------------------------------
 arbeite an einer 2027er Version:
- Freecad Makro für Gehäuse (mehrsprachig) + mehrere Halterungen, flexibel für beliebige ESP32 Boards, Schriftart kann selbst gewählt werden etc
- Software 1 ESPHome, Anzeige von Stati aus Home Assistant (Alarm, Lüften, Akkustand eines Gerät (z.B. Solar Akku))
- Software 2 Version analog für Arduino und ohne Home Assistant Abhängigkeiten und somit ohne Anzeige der Stati oder diese via http request füllen
- 31+ Sprachen und Dialekte
