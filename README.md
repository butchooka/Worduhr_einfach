- Scad/Freecad Makro für Gehäuse (mehrsprachig) + mehrere Halterungen, flexibel für beliebige ESP32 Boards, Schriftart kann selbst gewählt werden etc
- Gehäusevarianten gedruckt + in gekauften Bilderrahmen eingefügt
- Software 1 ESPHome, Anzeige von Stati aus Home Assistant (Alarm, Lüften, Akkustand eines Gerät (z.B. Solar Akku))
- Software 2 Version analog für Arduino und ohne Home Assistant Abhängigkeiten und somit ohne Anzeige der Stati oder diese via http request füllen
- 31+ Sprachen und Dialekte
